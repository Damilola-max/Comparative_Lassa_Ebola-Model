## Comment 3.1 - Biological Implications Extend Beyond the Analyzed Dataset

**Reviewer concern:** The manuscript combines conservation analysis, entropy-based site characterization, ESM-2 embeddings, and machine learning classification in a single workflow, but the biological implications stated in the Abstract and Discussion exceed what the analyzed datasets (780 LASV S-protein sequences; 1,610 EBOV Makona sequences) can support.

**Response:**

We fully accept this concern and have made the following revisions:

**1. Interpretive scope paragraph added at the opening of the Discussion (line 233):**

> *"The findings reported in this study are robust within the analyzed cohort (780 LASV S-protein sequences; 1,610 EBOV Makona-era sequences), but biological extrapolation beyond this sampling frame requires caution. Generalization to other LASV proteins (L segment), other EBOV species (Sudan, Bundibugyo), or temporal contexts outside the sampled period requires explicit external validation. Wherever implications for surveillance or vaccine design are discussed, they should be read as hypotheses generated by computational analysis rather than experimentally confirmed recommendations."*

**2. Abstract revised** to replace broad generalizations with dataset-bounded language. 'Understanding the differential mutational constraints governing these viruses' is now qualified as: *'within the analyzed cohort of Makona-era EBOV sequences and West African LASV S-protein sequences.'*

**3. Limitations and Future Directions section (lines 257-263)** now explicitly lists: Makona epoch constraint, S-protein-only LASV sampling, and need for Sudan/Bundibugyo and L-segment data before broader generalization.

## Comment 3.2 - Dataset Composition and Exact Proteins Not Sufficiently Described

We have added a dedicated subsection **'Dataset Composition and Metadata Summary'** to the Methods (lines 46-55) containing **Table D1**, which now makes the scope asymmetry immediately visible:

| Virus | Sequence Scope | Mean Length (aa) | Temporal Span |
|-------|---------------|-----------------|---------------|
| LASV  | S-protein (GP precursor only) | 1,119 | Multi-year |
| EBOV  | Makona full-genome assemblies | 6,332 | 2013-2016 |

The accompanying text (line 55) states: *"The LASV cohort is protein-focused (S-segment glycoprotein), whereas the EBOV cohort derives from full-genome assemblies; this difference in sequence scope is intrinsic to the source repositories and is acknowledged as a comparative limitation."*

Full sequence-level metadata including accession IDs and duplicate flags is provided in **Supplementary Table 1** (`validation_artifacts/tables/sequence_level_metadata.csv`).

## Comment 3.3 - ESM-2 Described as Central but Classifier Is Composition-Based

**Reviewer concern:** ESM-2 is presented as a central component of the framework (it appears in the title 'ESM-embedR'), yet the deployed classifier operates on 21-dimensional amino acid composition features, not ESM-2 embeddings. This inconsistency is confusing.

**Response:**

We have added an explicit **'Clarification on ESM-2 role'** paragraph in Methods (line 81):

> *"ESM-2 embeddings (1,280-dimensional) were generated for comparative embedding-space analysis (centroid distances, outlier detection, PCA visualization). However, the supervised classifier operates on lightweight, interpretable composition features (sequence length + amino-acid frequencies) rather than ESM-2 embeddings. This design prioritizes deployment efficiency and interpretability."*

An **ablation study** (Results line 229; Supplementary Table 2 at `validation_artifacts/tables/ablation_summary.csv`) comparing composition-only, ESM-2-only, and hybrid features demonstrates that all three achieve near-perfect discrimination on this dataset, confirming that composition features are sufficient while ESM-2 adds unique value for embedding-space characterization.

The title 'ESM-embedR' refers to the embedding-space characterization pipeline, not to the classifier. The abstract has been revised to state this distinction clearly.

## Comment 3.4 - Perfect Classification Performance Not Well Validated

**Reviewer concern:** Perfect held-out classification metrics (all 1.000) are not well validated. The performance likely reflects the separability of the dataset rather than true predictive ability.

**Response:**

We agree. The ~5-fold sequence-length difference between LASV (~1,119 aa) and EBOV (~6,332 aa) means a simple length feature would near-perfectly discriminate these classes. Revisions:

**1. Explicit framing in Results (line 220):**

> *"This near-perfect performance reflects strong class separability in the current dataset rather than proof of generalizable predictive power on independent or future sequences. The perfect metrics should be interpreted cautiously: they indicate that the current LASV and EBOV sequences are readily separable using composition features, not that the model will generalize to all future variants or to other filoviruses/arenaviruses."*

**2. Cross-validation added (Supplementary Table 3):** repeated stratified K-fold and grouped K-fold CV with 95% confidence intervals (`validation_artifacts/tables/validation_summary.csv`), visualized in Supplementary Figure 1 (`validation_artifacts/figures/validation_split_comparison.png`).

**3. Limitations (line 259):** explicitly states that equivalent performance on truly independent collections cannot be assumed without further validation.

## Comment 3.5 - Atypicality Scoring Not Biologically Validated; Terminology Is Misleading

**Reviewer concern:** The scoring framework uses terminology that implies clinical or biological validation that does not exist. Users of the deployed application receive narratives that could mislead them into treating statistical atypicality as biological pathogenicity.

**Response:**

This is the concern that prompted the most comprehensive revision. We have:

**1. Replaced all 'risk' terminology with 'atypicality' language** throughout the manuscript (`Comparative_Analysis_Refined_3_1.md`), codebase (`src/models/predict.py`), and deployed application (`app.py`). The five bands are now: Low (<20), Below-Average (20-39), Average (40-59), Elevated (60-79), and High (>=80). These names describe statistical position, not biological severity.

**2. Added bold disclaimer in Methods (line 83):**

> **"Important:** This index reflects statistical deviation from training-population centroids (computational atypicality), not a clinically validated mutation-risk probability. Correlation with experimental fitness data would be required before any clinical risk interpretation."*

**3. Persistent disclaimer on the deployed application** (https://mutation-analysis.streamlit.app):

> *"Atypicality is a statistical deviation index based on distance from known class patterns in training data. This index reflects statistical deviation from training data, not a validated clinical risk assessment."*

**4. Out-of-distribution flag added:** Sequences with atypicality index >= 90 are flagged with: *'This sequence scores in the extreme atypicality range. It may lie substantially outside the training distribution - interpret with caution.'*

## Comment 3.6 - Independent App Testing Revealed Misclassifications and Unrealistic Atypicality Assignments

**Reviewer concern:** Reviewer 3 independently tested the deployed application and observed misclassifications of reference sequences and unrealistic atypicality scores, raising concerns about the robustness of the deployment.

**Response:**

We are grateful for this independent testing - it constitutes a form of external validation not present in the original submission. We address the two reported issues directly:

**Regarding misclassifications:**

The classifier is trained exclusively on LASV S-protein sequences (~1,119 aa) and EBOV Makona full-genome assemblies (~6,332 aa). Any sequence outside this length and composition distribution - including partial sequences, sequences from Sudan or Bundibugyo EBOV, LASV L-segment sequences, or heavily ambiguous sequences - may be misclassified because it falls outside the training distribution. The application now displays explicit warnings:

- Input and cleaned sequence lengths are shown so users can identify preprocessing effects
- A warning is displayed when cleaned length differs substantially from input length
- The training scope is stated in the application sidebar: 'Trained on LASV S-protein (~1,100 aa) and EBOV Makona full-genome (~6,300 aa) sequences'

The `clean_sequence()` function in `src/features/sequence_features.py` removes all non-canonical characters, which can dramatically shorten sequences containing ambiguous residues, stop codons, or gaps. This preprocessing behavior is now disclosed in the UI.

**Regarding unrealistic atypicality assignments:**

The formula `index = clip(50 + 15z, 0, 100)` maps z-scores linearly to [0, 100]. Sequences far outside the training distribution produce extreme z-scores that saturate at 0 or 100. This is a known limitation of centroid-distance scoring, now disclosed in Methods (line 83) and in the application. Sequences with index >= 90 trigger the explicit out-of-distribution flag described above.
